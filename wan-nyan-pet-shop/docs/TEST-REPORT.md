## ユニットテスト（`tests/unit/`）

DOM を一切使わないので、CI でもブラウザなしで走ります。

### `rng.test.mjs`（7 件）
乱数の決定性・範囲・端点・シリアライズ復元。`int()` が両端を含むこと、
シード 0 でも縮退しないことを含みます。

### `pets.test.mjs`（17 件）
* 生成直後のステータスが範囲内であること
* 減衰レートがバランス表と一致すること（高級フードで実際に遅くなること）
* お世話の成否ルール（満腹・クールダウン・所持金不足・疲労・睡眠中のなでる）
* 性格によるなつき度の差
* 放置でけんこうが減り、世話で戻ること
* コンディション/きぶん/要求バブルの境界
* 4,000 ステップ歩き回っても座標が NaN にならず床から出ないこと

### `customers.test.mjs`（14 件）
品定めのスコアリング（種類・性格・健康）、価格がコンディション・なつき度・評判で
上がること、下限価格、辛抱の切れかた、選んだ子が居なくなったときの復帰、
来店間隔が上下限に収まること。

### `state.test.mjs`（24 件）
* 同じシードで完全に同じ展開になること
* 開店中以外はクリックが無効なこと
* 失敗したお世話でお金が減らないこと
* よごれ掃除、よごれの上限
* 動物病院（ペットは失われない）
* おむかえの入金・評判・アルバム記録
* 日締め（家賃の二重請求がないこと、`closeDay` の冪等性）
* 破産・エンディング（1 回だけ発火すること）
* 翌日処理（よごれのクリア、休息、ベッド上限を超えないこと、無人にならないこと）
* アップグレード購入と上限、おむかえの空きチェック
* イベントバス（購読者が例外を投げてもシミュレーションが止まらないこと）

### `save.test.mjs`（9 件）
セーブ→ロードの完全復元、復元後も同じ乱数系列で進むこと、壊れたセーブ・
別バージョン・ストレージ例外・ストレージ無しをすべて握り潰すこと、
復元後に生成するペットの ID が衝突しないこと。

### `loop.test.mjs`（8 件）
固定タイムステップの歩数、タブ復帰時のキャッチアップ上限（暴走しない）、
ポーズ中に描画は続くがシミュレーションは止まること、解除時に早送りされないこと、
2 倍速、パーティクルプールが増えないこと。

### `longplay.test.mjs`（5 件）
* **自動プレイのボットが 10 日間生き延び、評判とおむかえ数が伸びること**（バランス回帰テスト）
* 放置プレイでも状態が壊れないこと（そして損をすること）
* ランダムクリック 6 分ぶんで不変条件（NaN なし・範囲内・配列が無限に伸びない）を維持
* 長時間走らせてもコンディションが 0〜100 を出ないこと
* 1 日がきっちり 120 秒であること

## E2E テスト（`tests/e2e/game.e2e.mjs`）

実際の Chromium で、実際のマウス・キーボードイベントを使います。
UI のクリックは描画時に登録される矩形（`Regions`）の中心を狙うので、
当たり判定そのものの検証にもなっています。

1. 起動してゲームが公開され、キャンバスが白紙でないこと（色数を数える）
2. タイトルの「はじめから」で開店すること
3. 道具バーのクリックとキー `1`〜`5` の両方で道具が変わること
4. ペットを実際にクリックして給餌され、40円引かれ、選択状態になること
5. おそうじツールでよごれが消えること
6. `Esc` でシミュレーションが止まり、解除で再開すること
7. ループが実時間どおりに進むこと（0.7 秒で 0.3〜1.2 秒ぶん）
8. せいさん → お店じゅんび → 翌日 をボタンクリックだけで通せること
9. アップグレードが購入でき、所持金とレベルが正しく動くこと
10. ポーズで自動セーブ → リロード → 「つづきから」で所持金・日数・ペットが復元されること
11. パーティクルを乱打してもプール上限（180）を超えないこと
12. ウィンドウサイズを変えても描画が続き、エラーが出ないこと
13. 実プレイ相当の操作を続けてもコンソールエラーが 0 件であること
